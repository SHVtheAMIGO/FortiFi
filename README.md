# 🛡️ FortiFi

**FortiFi** is a modern front-end web project that presents a clean and user-friendly cybersecurity landing page.  
It visually demonstrates features like WiFi protection, parental control, real-time alerts, and pricing — all built using simple web technologies.

🔗 **Live Demo:** https://shvtheamigo.github.io/FortiFi/

---

## 📌 About the Project

FortiFi is a **static front-end project** designed to showcase how a cybersecurity service website could look and feel.  
The focus is on **UI clarity, responsiveness, and simplicity**, making it easy for users to understand security features without technical complexity.

This project is purely front-end and does **not** include any backend or real data collection.

---

## ✨ Features

- 🔐 WiFi Security Protection (UI showcase)
- 👨‍👩‍👧 Parental Control section
- 🚨 Real-time Alert display (mocked)
- 💸 Pricing plans with clean layout
- 📱 Responsive and modern design
- 🎨 Minimal and readable UI

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
- **Vanilla JavaScript** – Basic interactivity  

No frameworks. No build tools. Just pure web fundamentals.
